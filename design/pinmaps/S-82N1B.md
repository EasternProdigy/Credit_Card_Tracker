# U3: ABLIC S-82N1B series (SNT-6A)
Source: ABLIC S-82N1B datasheet Rev.1.2_00: "Pin Configuration" Table 6 / Figure 2 (p.5); Product name list Tables 2-5 (p.3-4); Absolute maximum ratings Table 7 (p.5); SNT-6A-A package drawing PG006-A-P-SD.

| Functional name | Pin | Description |
|---|---|---|
| PS | 1 | Power-saving signal input |
| CO | 2 | Charge FET gate (CMOS out) |
| DO | 3 | Discharge FET gate (CMOS out) |
| VSS | 4 | Negative supply (cell -) |
| VDD | 5 | Positive supply |
| VM | 6 | Overcurrent detection |

## Variant (closes O7, with a change)
Standard variants only: AA (VCU 4.310 V, VCL 4.110, VDL 2.800, VDU 3.000, VDIOV 0.039 V), AB (4.370 V), AC (4.410 V). **There is no stock 4.20 V VCU part, and a 4.20 V VCU would trip at the charger's own 4.20 V regulation point.** The protector is a backup above the charger, so pick **S-82N1BAA-I6T1U7** (4.31 V). Lower thresholds need an ABLIC custom order.
- PS (function combination 1): active "H", internal 5 MOhm pull-down. VPSH >= 0.90 x VDD (3.78 V at 4.2 V), so a 3.3 V GPIO cannot drive it high reliably. v1: PS to VSS (BT_NEG) through a 0R jumper plus a test pad, so ship mode can be tried by hand.
- Discharge overcurrent: 0.039 V / (2 x RDS(on) of Q1). With 2 x 25 mOhm that is about 0.78 A.
