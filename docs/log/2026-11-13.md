# 2026-11-13

## Session: design phase recap (before the repo existed)
**Who:** Dwayne + Claude (claude.ai design sessions)
**Area:** whole project

### What we did
- Defined the goal: a credit-card-size tracker for the outside leather pocket of a Double Oak Essentials bifold. It tracks via Google Find Hub (priority, Dwayne runs GrapheneOS) and Apple Find My, charges wirelessly over Qi, and is as thin as possible.
- Competitive analysis of commercial wallet cards and open-source trackers, then a deep research pass on chips, firmware, location retrieval and thin-board manufacturing.
- Picked the stack: nRF54L15 + Everytag firmware (alternating Find My and FMDN frames), BQ51003 Qi receiver, BQ25101 charger, Grepow 135 mAh 0.85 mm cell, S-82N1B protector, TPS7A02 LDO, printed IFA antenna with an L-match.
- Server plan: Raspberry Pi running GoogleFindMyTools + an Apple fetcher, feeding Traccar, alerts via ntfy, a custom PWA for phone and desktop with item bundles. Fedora box as backup.
- Ran verification sims: Qi coupling and link (ngspice), charge and thermal, power path, battery Monte Carlo, antenna (PyNEC) on the real floorplan, protocol round-trip, server end-to-end. See `reports/VERIFICATION_REPORT.md`.
- Built the design review page and the KiCad handoff package (rev 0.4).

### Results
- Battery life median 10.7 months; charge time about 2.2 h.
- Card thickness 1.05 mm nominal, 1.137 mm worst case with slim skins.

### Decisions
- Slim PET skins, after the first 3D model looked too thick.
- Right side clear window showing the electronics, left side for Dwayne's artwork.
- Qi tank cap issue fixed by splitting C1 into 3 × 0402 X7R (100 + 100 + 33 nF) and C2 into 2.2 nF + 330 pF C0G.
- Process: v1 is a debuggable dev board, v2 is the final card, v3 if needed. About a month total.
- Everything gets documented and open-sourced.

### Problems and surprises
- First FMDN demo had the flag bit positions wrong; fixed against the spec.
- First antenna sim assumed an ideal ground plane; re-simulated on the real floorplan, which is why the L-match exists.

### Next step
- Order parts (DK, PPK2, coils, cells). NanoVNA already bought.
- Start firmware on the DK and the v1 dev board layout in KiCad.
