# Build log

One file per day (`YYYY-MM-DD.md`), written by Dwayne and the Claude sessions working on this project. It records what was designed, tested, measured, decided and broken, in order.

- Raw data for any measurement is in `../../measurements/<date>/`, each file with a `.md` note next to it.
- Lasting decisions are summarized in `../10_decision_log.md`.
- Start a new day from `TEMPLATE.md`.
